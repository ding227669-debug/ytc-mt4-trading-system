# YTC 价格行为 · 多周期趋势跟随策略（应用版）

> 来源：Lance Beggs《The YTC Price Action Trader》思想 + Al Brooks 价格行为体系 + Elder 三重滤网框架
> 适用品种：黄金 XAUUSD / 白银 XAGUSD / 原油 WTI / 比特币 BITCOIN（Alpari 符号）
> 目标：把"大周期定方向、关键位验证、回调顺势进场"变成可执行、可检查、可复盘的系统

---

## 一、策略总纲（一句话）

**大周期定方向，中周期找关键位，小周期等回调；只在顺势方向、只在被验证过的关键位进场；止损永远放在关键位外侧。**

## 二、周期框架

| 层级 | 周期 | 作用 |
|---|---|---|
| 大周期 | 日线 D1（H4 辅助） | 定方向：多/空/震荡 |
| 中周期 | H1（H4 辅助） | 找关键位、验证结构 |
| 小周期 | M15（M5 辅助） | 等回调、找反转信号、精确进场 |

新手纪律：**先只做 D1 级别**，信号少但质量高，每周 1-3 单。

## 三、方向判定（大周期，纯价格结构，不靠指标）

**多头（只做 BUY）**：收盘价在 MA200 之上 **且** 结构为 HH+HL（高点抬高、低点抬高）
**空头（只做 SELL）**：收盘价在 MA200 之下 **且** 结构为 LH+LL
**震荡（不交易）**：以上都不满足 → 空仓等待

**共振过滤**：D1 与 H4 方向一致才交易；方向矛盾 → 跳过。
（这是视频第1-3步的量化版）

## 四、关键位定义（中周期）

候选关键位（按优先级）：
1. **显著摆动点**：被触碰过的前高/前低（H1 级别起）
2. **大周期结构位**：D1/H4 的 HH / HL / LH / LL 所在价位
3. **整数关口**：黄金每 50 整数（4400/4450…）、比特币每 2000（78000/80000…）、原油每 5、白银每 1
4. **流动性池**：前高上方 / 前低下方的止损堆区域

**验证标准（"三次触碰"量化版）**：
- 触碰定义：K线影线触及该区域即算一次
- 小级别位：±0.2% 范围内被触碰 ≥3 次 → 有效
- 大级别结构位：触碰 ≥2 次即可（级别权重更高）
- 从未被触碰的新位：**不进场**，等验证

## 五、进场（小周期，等回调）

**五条件全部满足才进场：**
1. 大周期方向 = 多头 → 只等 BUY；空头 → 只等 SELL
2. 价格回调到已验证关键位
3. M15 出现顺势反转信号：
   - **吞没**（Engulfing）：阳线完全吃掉前一根阴线（做多时）
   - **Pin Bar**：长影线 + 小实体，影线探到关键位后收回
   - **Inside Bar 突破**：内包K线后向交易方向突破
4. 信号方向与交易方向一致
5. 无破位：价格**没有**快速击穿关键位（击穿 = 放弃或等重新验证）

**进场方式**：反转信号K线收盘后市价进场；或挂单在信号K线极值。

## 六、止损 · 仓位 · 止盈（资金管理是灵魂）

- **止损**：关键位外侧 + 缓冲（0.1% 或 0.5×ATR），做多放关键位下方
- **仓位**：单笔风险 = 账户 **1%**（1000 美元 = 10 美元风险）
  手数 = 风险金额 ÷（止损距离 × 合约每点价值）
- **止盈**：≥ 1:2 盈亏比；优先前高/前低/对称目标
- **移动止损**：盈利 ≥1R → 止损移到成本（保本）；盈利 ≥2R → 止损跟到最近结构位
- **熔断**：单日亏损 ≥3% 停止当天；连亏 2 单强制休息复盘

## 七、禁止交易清单（过滤器）

1. 大周期震荡，无明确方向
2. 关键位未被验证（触碰次数不够）
3. 价格快速击穿关键位（破位）
4. 重要数据发布前后 30 分钟（黄金/原油尤其：非农、CPI、EIA、FOMC）
5. 周末/流动性极薄时段（比特币周日点差可达平时的数倍）
6. 情绪化状态（连亏后、梭哈冲动、报复性交易）

## 八、每单执行检查清单（全 ✅ 才下单）

- [ ] 1. D1 方向明确（多/空，非震荡）
- [ ] 2. H4 与 D1 方向一致（共振）
- [ ] 3. 价格已回调到候选关键位
- [ ] 4. 关键位触碰次数达标（≥3 次或大级别 ≥2 次）
- [ ] 5. M15 出现顺势反转信号
- [ ] 6. 止损位确定（关键位外侧+缓冲）
- [ ] 7. 手数按 1% 风险计算
- [ ] 8. 止盈 ≥ 2R
- [ ] 9. 不在数据发布窗口
- [ ] 10. 心态平静，计划清晰
