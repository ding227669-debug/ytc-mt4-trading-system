# YTC 价格行为策略（应用版）

> 出处：Lance Beggs《The YTC Price Action Trader》+ Al Brooks 价格行为 + Elder 三重滤网
> 品种：黄金 XAUUSD / 白银 XAGUSD / 原油 WTI / 比特币 BITCOIN（Alpari 符号）
> 一句话：**大周期定方向，中周期找关键位，小周期等回调；只在顺势方向、只在被验证关键位进场；止损永远在关键位外侧。**

## 周期框架

| 层级 | 周期 | 作用 |
|---|---|---|
| 大周期 | D1（H4 辅助） | 定方向 |
| 中周期 | H1（H4 辅助） | 找关键位、验证结构 |
| 小周期 | M15（M5 辅助） | 等回调、反转信号、精确进场 |

新手纪律：先只做 D1 级别，每周 1-3 单。

## 方向判定（D1，纯结构，量化版）

- **多头**：收盘 > MA200 且结构 HH+HL（高点/低点抬高）
- **空头**：收盘 < MA200 且结构 LH+LL
- **震荡**：其他 → 不交易
- **共振过滤**：H4 方向须与 D1 一致（偏多/偏空算共振）；矛盾 → 跳过

## 关键位（H1/H4）

候选（按优先级）：显著摆动点（前高前低）> 大周期结构位（D1/H4 的 HH/HL/LH/LL）> 整数关口（黄金每50、比特币每2000、原油每5、白银每1）> 流动性池。

**验证（"三次触碰"量化版）**：
- 触碰 = K线影线触及 ±0.2% 区域
- 小级别位 ≥3 次有效；大级别结构位（D1）≥2 次即可
- 从未触碰的新位 → 不进场

## 进场（M15，五条件全满足）

1. 大周期方向明确（多→只做 BUY；空→只做 SELL）
2. 价格回调到已验证关键位
3. M15 顺势反转信号：吞没 / Pin Bar（影线 ≥2×实体）/ Inside Bar 突破
4. 信号方向与交易方向一致
5. 无破位（价格没快速击穿关键位；击穿 → 放弃或等重新验证）

进场方式：信号K线收盘后市价，或挂单在信号K线极值。

## 止损 · 仓位 · 止盈

- 止损：关键位外侧 + 缓冲（0.1% 或 0.5×ATR），做多放下方
- 仓位：单笔风险 = 账户 **1%**（1R）；手数 = 风险金额 ÷（止损距离 × 点值）
- 止盈：≥1:2；优先前高/前低/对称目标
- 移动止损：盈利 ≥1R → 移成本保本；≥2R → 跟最近结构位
- 熔断：单日 -3% 停手；连亏 2 单强制休息复盘

## 禁止交易清单

1. 大周期震荡
2. 关键位未验证
3. 价格快速击穿关键位
4. 重要数据前后 30 分钟（非农/CPI/EIA/FOMC）
5. 周末/流动性极薄（比特币周末点差可达 40+ 美元）
6. 情绪化（连亏后、报复性交易）

## 每单检查清单（全 ✅ 才下单）

1. D1 方向明确（非震荡）
2. H4 与 D1 共振
3. 价格已回调到候选关键位
4. 关键位触碰达标
5. M15 出现顺势反转信号
6. 止损位确定（关键位外侧+缓冲）
7. 手数按 1% 风险
8. 止盈 ≥2R
9. 不在数据窗口
10. 心态平静、计划清晰

## 复盘

每单记：品种/方向/手数/进出场价/理由（哪个关键位、几次触碰、什么信号）/结果（+R/-R）/执行偏差。
30 单后统计：胜率、平均盈亏比、期望值（胜率×均盈 − 败率×均亏）；期望为负 → 停止，回查过滤器。

## 已知特性（别慌）

- 震荡市连续小亏 -1R 是正常现象（趋势周才赚钱）
- 单边暴涨（V 型）会踏空主升浪——共振确认滞后是固有代价
- 周末过滤器会误伤个别盈利单，但长期期望为正
- 胜率 50% 上下即可盈利（靠 2R 止盈 × 1R 止损的盈亏比）
