# 宏观思维雷达（Masters' Macro Radar）

> 方法论：**不听他们说什么，看他们做什么**。自传/访谈是事后合理化；只有可核实的动作（13F、公告、战例）算证据。说法×动作交叉验证后，只保留被动作验证的模型。

## 核心结论（v1，8 人已验证）

1. **危机恐慌 = 买入时机**（巴菲特 08/11、马克斯 08/20）——恐慌暴跌日备现金，YTC 信号可放大
2. **央行放水周期 = 硬资产顺风**（都铎 2020 比特币/黄金、达里奥 2020s 黄金）——宽松周期黄金/比特币基调偏多
3. **泡沫狂热 = 离场时机**（巴菲特 2007 中石油、德鲁肯米勒 2000）——狂热期只做最顺趋势、降仓
4. **无人能预测时点**（索罗斯 2000、达里奥 2020、保尔森 2011）——宏观管方向，时点交给 YTC
5. **活下来 > 赚钱**（德鲁肯米勒/都铎/马克斯）——1% 风险+熔断 = 大师同款纪律

## 每周雷达流程（5 分钟）

```
① 债务周期：央行宽松还是紧缩？→ 黄金/比特币基调
② 情绪钟摆：恐惧还是贪婪？（VIX/新闻热度）→ 激进 or 保守
③ 反身性：当前趋势自我强化还是衰竭？→ YTC 信号可信度
④ 商品周期：原油/白银供需位置？→ 长线方向
⑤ 政治风险：政策/地缘拐点信号？→ 降仓开关
```

## 品种映射

- 黄金：债务周期 + 实际利率（顺风=宽松/购金）
- 白银：放水 + 工业周期（波动 > 黄金）
- 原油：供需周期 + 地缘脉冲（战争=短期暴涨后回落）
- 比特币：反身性（趋势衰竭识别）+ 放水顺风

## 注意事项

- 雷达是"背景色"不是"触发器"：管敢不敢进、进多重，不管何时进（YTC 管）
- 当前宏观定位判断前必须核实最新数据（利率、央行资产负债表、VIX、铜金比）——勿用过期定位
